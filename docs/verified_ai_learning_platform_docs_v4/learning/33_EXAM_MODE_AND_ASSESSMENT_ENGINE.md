# Exam Mode and Assessment Engine

## ExamDefinition

Versioned canonical data:
- code/name,
- sections,
- skill weights,
- timing,
- scoring rules where supported,
- question type distribution.

## UserExam

Adds:
- target date,
- target score optional,
- personal schedule,
- active/completed status.

## Readiness

Derived from mastery, confidence, exam weights and assessment evidence. It is an estimate, not a guarantee.

## Mock exam

Properties:
- blueprint,
- timed/untimed,
- hints disabled in exam mode,
- question selection constraints,
- stable scoring,
- attempt capture.

AI-generated questions must pass validation before being treated as reliable assessment evidence.

## Post-exam report

- raw score,
- skill breakdown,
- mistake category distribution,
- time-management signals,
- readiness update,
- study-plan recommendations.

## Final review

Near exam prioritize:
- high-weight weak skills,
- repeated mistakes,
- due review,
- representative mixed practice.

## Integrity

Product prepares students; it is not designed to bypass active proctoring or assessment restrictions.
