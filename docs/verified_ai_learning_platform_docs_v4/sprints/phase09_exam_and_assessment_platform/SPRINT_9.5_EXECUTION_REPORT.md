## Implemented Invariants & Guardrails
- **Deterministic Penalty & Point Scoring (`DeterministicExamScoringPolicy`, `ScoringFormulaPolicy`, `INV-EXAM-004`):** Implements ÖSYM penalty arithmetic ($\text{Net} = C - \text{penaltyRatio} \cdot W$, defaulting to `0.25`) rounded via `HALF_UP` to 2 decimal places (`net_score`), raw point sums, accuracy rate, wrong/blank/correct counts, per-topic and per-difficulty breakdowns, and distractor/misconception traceability with `llm_tokens_used = 0` and `inference_cost_usd = 0.000000`.
- **Scorable Lifecycle Gate & Audit-Logged Regrading (`ExamScoringEngineService`, `ExamScoringController`):** Permits scoring only for terminal scorable statuses (`SUBMITTED`, `EXPIRED_AUTO_SUBMITTED`), rejecting active/non-scorable sessions (`IN_PROGRESS`, `OFFLINE_GRACE_BUFFER`, `ABANDONED`) with `HTTP 409 EXAM_SESSION_NOT_SCORABLE`. Preserves score snapshots and records explicit administrative/owner regrade transitions (`score_version` increment, `previous_net_score`, `new_net_score`, `reason_code`, `reason_detail`, `triggered_by`) in `exam_score_regrade_audits`, rejecting blank/invalid regrade reasons with `HTTP 400 EXAM_REGRADE_INVALID_REQUEST`.
- **F28 Scratchpad & Ownership Evidence Traceability (`ExamSessionItemEvaluation`):** Anchors every evaluated item to `question_item_id`, `question_code`, `topic_code`, `difficulty_band`, `cognitive_level`, `format_type`, selected/numeric responses, expected key/value, scratchpad asset count + `F28ScratchpadTraceStatus`, and enforces BOLA user ownership (`HTTP 403 EXAM_SESSION_FORBIDDEN`) across live API and local SQLite cache.
- **GDPR / KVKK Privacy Cascade (`ExamPrivacyLifecycleContributor`):** Exports Sprint 9.5 score snapshots, item evaluations, and regrade audit rows, and deletes child tables first (`exam_score_regrade_audits` -> `exam_session_item_evaluations` -> `exam_session_scores`) before parent runtime rows.
- **Native Swift 6 Concept B Score Summary (`ExamScoreSummaryView`, `ExamScoreSummaryViewModel`, `ExamOfflineSQLiteStore`):** Flat zero-gradient, zero-shadow, zero-purple `ColorTokens` layout with net score hero card, formula badge, correct/wrong/blank counters, topic & difficulty breakdowns, `All`/`Wrong`/`Blank` item evidence filter, regrade audit log + regrade action, offline SQLite cache (`exam_cached_score_summaries` with per-user isolation and purge), and 37 EN/TR `Localizable.xcstrings` keys (`379` total verified).
