## Runtime enforcement and deterministic exemption matrix

| Operation / Endpoint | Tier / Quota Rule | Exhausted / Circuit-Breaker Behavior | Idempotency & Concurrency |
|---|---|---|---|
| `DETERMINISTIC_TWIN` & `DETERMINISTIC_SYMBOLIC_VERIFY` (`services/math-verifier/`) | Exempt (`requiresPaidQuota = false`, `INV-QUOTA-001`) | Always allowed (`$0.00` AI cost, `deterministicTwinsUnlimited = true`, `degradedToDeterministicOnly` does not block) | Zero quota consumption rows created |
| `PrimarySolveService.start` / `run` (paid LLM routes) | `FREE`: 3/day & `$0.08`/mo; `PRO`: 150/mo & `$2.50`/mo; `COACH_PRO` / `YKS_SEASON_PASS`: 400/mo & `$4.20`/mo | `start`: HTTP 429 (`QUOTA_EXHAUSTED` or `AI_COST_CIRCUIT_BREAKER_TRIPPED`); `run`: `SolveState.POLICY_BLOCKED` without provider dispatch | Advisory lock + `FOR UPDATE` + `ai-op:<operationId>` shared with `PostgresAiSpendGuard` |
| `SecondarySolveService.evaluate` / `run` (paid LLM routes) | Same tier allowance as `AI_VERIFICATION` | Blocks secondary escalation gracefully (`Outcome.BLOCKED` / `SecondaryState.POLICY_BLOCKED`) keeping primary/deterministic flow intact | Advisory lock + `FOR UPDATE` + `ai-op:<operationId>` |
| `PostgresAiSpendGuard.reserve` / `report` (`V016`/`V017`) | Coordinates per-user `QuotaLedgerService` (`VISION_PARSE` -> `HANDWRITING_DIAGNOSTIC`, `PRACTICE_GENERATE` -> `HYBRID_TWIN`, others -> `AI_VERIFICATION`) | Commits `cost_circuit_breaker_tripped = TRUE` in `REQUIRES_NEW` tx before throwing `BUDGET_EXCEEDED`; releases fresh reservation if `V017` rejects | Reconciles actual USD micros on `report(...)` |
| `GET /v1/billing/entitlements` & `GET /api/v1/billing/entitlements` | Additive `quotaSummary` object on `EntitlementV2` | `quota-ledger-enabled=false` returns zero-usage deterministic `quotaSummary` with zero DB writes | `GET /api/v1/me/entitlements` (`EntitlementResponse`) completely unchanged |
