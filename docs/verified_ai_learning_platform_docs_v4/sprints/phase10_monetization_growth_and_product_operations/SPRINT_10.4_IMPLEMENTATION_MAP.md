## Sprint 10.5 consumer SPI contract (`NotificationSchedulingPort`)

| Method / Contract Type | Signature / Purpose | Fail-Closed & Concurrency Semantics |
|---|---|---|
| `schedule(ScheduleNotificationCommand)` | Accepts `userId`, `idempotencyKey`, typed `NotificationCategory`, `NotificationIntentType`, `NotificationChannel`, `locale`, `templateKey`, `templateParams`, `deepLinkPath`, `scheduledFor`, `expiresAt`, `sourceModule`, `correlationId`. | When `enabled=false`, returns `SUPPRESSED(FEATURE_DISABLED)` with zero DB writes. When `enabled=true`, serializes per user via advisory lock in `REQUIRES_NEW` tx; same `(userId, idempotencyKey)` + same `payloadHash` replays (`replayed=true`), mismatched `payloadHash` throws `409 NOTIFICATION_IDEMPOTENCY_CONFLICT`. |
| `cancel(UUID userId, UUID deliveryId, String reasonCode, String correlationId)` | Cancels pending delivery owned by `userId`. | Foreign or absent delivery throws `404 NOTIFICATION_DELIVERY_NOT_FOUND`; terminal or `DISPATCHING` states throw `409 NOTIFICATION_ILLEGAL_STATE_TRANSITION`. |
| `getPreferences(UUID userId)` | Returns `NotificationPreferenceView` (`schemaVersion = notification-preferences-v1`). | Returns persisted preferences or default opt-out snapshot (`pushEnabled=false`, quiet hours `22:00`–`08:00` UTC, `dailyCap=2`) with zero DB writes. |
