# Sprint 10.5 implementation map

Base: Sprint 10.1 (`V065`), Sprint 10.2 (`V066`), Sprint 10.3 (`V067`), and Sprint 10.4 (`V068`, `NotificationSchedulingPort`) preserved untouched (`verifiedai.notification.enabled: false`, `dispatch-worker-enabled: false`, `apns-live-delivery-enabled: false`, `lifecycle-campaigns-enabled: false`, and `lifecycle-scheduler-enabled: false` by default).

## 4+1 learning-relevant trigger, cooldown, and cancellation matrix

| Category / Intent | Owning Module | `templateKey` & Allowed Params | `deepLinkPath` | Cooldown & Eligibility | Auto-Cancellation |
|---|---|---|---|---|---|
| `STUDY_PLAN` / `STUDY_PLAN_DAILY_MISSION` | `studyplan` | `notification.template.study_plan.daily_mission` (`budgetMinutes`, `remainingTasks`) | `verified-ai://study-plan/today` | `20h` cooldown; `COMPLETED` today -> `SKIPPED_ALREADY_COMPLETED` | `DailyCoachSessionService.completeTask` / `downshiftMission` reaching `COMPLETED` |
| `SPACED_REVIEW` / `SPACED_REVIEW_DUE` | `studyplan` | `notification.template.spaced_review.due` (`dueCount`, `triggerKind`) | `verified-ai://spaced-review` | `24h` cooldown; completed today -> `SKIPPED_ALREADY_COMPLETED`; empty due queue -> `SKIPPED_NOT_ELIGIBLE` | `SpacedReviewService.completeQueueItem` / `dismissQueueItem` clearing due queue |
| `EXAM_DEADLINE` / `EXAM_DEADLINE_COUNTDOWN` | `exam` | `notification.template.exam_deadline.countdown` (`examCode`, `daysRemaining`) | `verified-ai://exam-readiness` | `24h` cooldown; calm milestones `{30, 14, 7, 2}` days only | `CandidateGoalUpdatedEvent` shifting exam code or target date |
| `BILLING_TRIAL_REMINDER` / `TRIAL_ENDING_48H_REMINDER` | `billing` | `notification.template.billing.trial_ending_48h` (`hoursRemaining`, `planCode`) | `verified-ai://subscription/manage` | Once per trial transaction (`expiresAt - 48h`, clamped to `now`) | `DID_RENEW`, `REFUND`, `REVOKE`, `EXPIRED`, or `autoRenewStatus == false` |
| `ACCOUNT_SECURITY` / `ACCOUNT_SECURITY_ALERT` | `identity` | `notification.template.account.security_alert` (`eventType`) | `verified-ai://account/security` | Exempt from cooldown, quiet hours, and daily cap | Not auto-cancelled |
