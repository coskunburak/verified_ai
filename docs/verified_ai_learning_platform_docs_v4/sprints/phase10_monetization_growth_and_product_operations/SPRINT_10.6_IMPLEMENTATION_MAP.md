## 7 AI economics / proprietary-model guardrail answers

Per `SPRINT_10.6_ANALYTICS_EVENT_CATALOG_AND_PRODUCT_METRICS_IMPLEMENTATION.md`:

1. **Does this add or multiply an inference call?** No. Sprint 10.6 adds `0` LLM/inference calls (`llmTokensUsed = 0`, `inferenceCostUsd = 0.00`).
2. **What is the expected invocation rate per learner action?** `0` inference invocations per learner action; telemetry writes strictly bounded metadata rows (`<= 2048` bytes properties) to PostgreSQL.
3. **Can deterministic code/cache remove the call?** Yes—event validation, SHA-256 fingerprinting, Learning OS KPI computation (`VITRR`, `DRPR-48h`, `DRPR-7d`, `MRRR-14d`, `TGI`), PostgreSQL `percentile_cont`, and unit-economics rollups are 100% deterministic Java and SQL.
4. **Can an economy-tier approved route satisfy the task?** Not applicable; zero AI routes are invoked.
5. **Is a secondary solver actually required, and what triggers it?** No secondary solver is used or triggered.
6. **What telemetry will reveal cost regression?** `ProductMetricsQueryService` computes `aiCostPerCompletedSolveUsd`, `aiCostPerPayingActiveLearnerUsd`, `aiCostPerVerifiedLearningSessionUsd`, and tier gross-margin proxies over `analytics_events`, `entitlement_quota_consumptions`, `entitlement_quota_ledgers`, and `ai_usage_records`; `AnalyticsMetrics` tracks `verifiedai.analytics.event.ingested.total`, `verifiedai.analytics.event.rejected.total`, and `verifiedai.analytics.metrics.query.duration`.
7. **Does this create data that might later be useful for training?** No; per `adr/ADR-006_PRODUCTION_STUDENT_DATA_NOT_TRAINING_DATA_BY_DEFAULT.md`, raw problem text, LaTeX, OCR output, and student solutions are banned from analytics (`422 ANALYTICS_PII_OR_RAW_CONTENT_REJECTED`), and both `analytics_events` and `analytics_daily_metric_rollups` enforce `training_eligible BOOLEAN NOT NULL DEFAULT FALSE CHECK (NOT training_eligible)`.

## SPI consumer contract & one-way Spring Modulith boundary

Downstream modules (`billing`, `attempt`, `mistake`, `mastery`, `studyplan`, `exam`, `tutoring`, `notification`, `identity`) may ONLY import `com.verifiedai.analytics.application` (`@NamedInterface("application")`):

- `AnalyticsEventPort.recordServerEvent(RecordAnalyticsEventCommand)` -> returns `AnalyticsIngestOutcome` (`ACCEPTED`, `REPLAYED`, or `REJECTED` with machine-readable `errorCode`).
- `RecordAnalyticsEventCommand` accepts strictly JDK types (`UUID`, `String`, `Instant`, `Integer`, `long`, `Map<String, Object>`) so callers never depend on `analytics.domain`, `analytics.infrastructure`, or `analytics.api`.
- `com.verifiedai.analytics.*` holds zero outbound Java dependencies on any peer business module; cross-table product metric queries run strictly as read-only SQL via `JdbcClient` inside `com.verifiedai.analytics.infrastructure.ProductMetricsJdbcRepository`.
