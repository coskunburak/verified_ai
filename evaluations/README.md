# Evaluations

Golden datasets, baselines, and reports will be added in AI evaluation phases. Phase 2 intentionally creates no protected holdouts, training datasets, or model artifacts.

Sprint 4.5 adds the first synthetic parser seed at `evaluations/parser/golden/problem-parse-v1-seed.json`. It is not a protected holdout or accuracy benchmark; it is a small governance seed for `problem-parse-v1` schema, semantic validation, unsupported handling, ambiguity handling, and future Sprint 4.10 expansion.
